# **Proposition**

## Main Idea
Proposition is declarative sentence that declares a fact, it can be either true or false but not both.

My example:
  - Binary number system is the foundation of modern computing. (This is a proposition, it returns truth value true)
  - Linux is widely used worldwide, powering infrastructures. (This is a proposition, it returns truth value true)
  - All computers use decimal number as foundation. (This is a proposition, it returns truth value false)
  - X + 9 = 12 (This is not a proposition)
