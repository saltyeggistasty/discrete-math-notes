# **Proposition Negation**

## Main Idea
Given a proposition *p*, negating the proposition means if the proposition has truth value of true, then its negation *¬p* has truth value of false, (and if a proposition is false, then its negation is true). other notations you
might see are *∼p*, *−p*, *p′*, *Np*, and *!p*.

My example:
  - *p*: "Linux IS used worldwide", then *¬p*: "Linux IS NOT used worldwide"
  - *q*: "Binary number system IS the foundation of modern computing", then *¬q*: "Binary number system IS NOT the foundation of modern computing"

The negation of a proposition always has truth value opposite to the original proposition. In other words, if *p* is true then *¬p* is false and if *p* is false then *¬p* is true.
