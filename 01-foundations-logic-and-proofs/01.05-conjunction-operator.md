# **Conjunction Operator**

## Main Idea
Let *p* and *q* be propositions, the conjunction of *p* and *q* is denoted by *p* ∧ *q* and has truth value of TRUE when both *p* and *q* are true, and is false otherwise.

My example:
  - *p*: "The sky is blue.", *q*: "1 + 1 = 2.", therefore *p* ∧ *q* = "The sky is blue AND 1 + 1 = 2." = TRUE, since both propositions has truth value of true.
  - *p*: "1 + 2 = 6.", *q*: "Binary number system is the foundation of modern computing.", therefore *p* ∧ *q* = FALSE, since *p* has truth value of FALSE.
  - *p*: "Chickens can fly to mars.", *q*: "Cats can drive bicycle", therefore *p* ∧ *q* = "Chickens can fly to mars AND cats can drive bicycle" = FALSE, since both *p* and *q* has truth value of FALSE.
