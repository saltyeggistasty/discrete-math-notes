# **Disjunction Operator**

## Main Idea
Let *p* and *q* be propositions, the disjunction of *p* and *q* is denoted by *p* ∨ *q* and has truth value of false when both *p* and *q* are false, and is true otherwise.

My example:
 - Let *p*: "Path A is the path to the restaurant", *q*: "Path B is also the path to the restaurant" then *p* ∨ *q*: "Path A is the path to the restaurant or path B is also the path to the restaurant." Both path led to the restaurant, if one of the path A or B or both lead to the restaurant, the truth value will be true, while if both does not lead to the restaurant, the truth value would be false.
  

Source:
Discrete Mathematics and Its Application, Kenneth Rosen (1.1.2 Proposition)<br>
