# **XOR Operator**

## Main Idea
Exclusive Or, and can be called as XOR is an operator such that *p* ⊕ *q* is true when exactly one of *p* and *q* is true, and is false otherwise.

| *p*     | *q*     | *p* ⊕ *q* |
|-------|-------|--------|
| true  | true  | false  |
| true  | false | true   |
| false | true  | true   |
| false | false | false  |

My example:
  - Let *p*: "Path A leads to the restaurant," and *q*: "Path B also leads to the restaurant." Then *p* ⊕ *q* is true when only one of *p* or *q* is true (when a person chooses only one of the paths, not both). For example, if a person chooses Path A, then *p* is true and *q* is false, resulting in *p* ⊕ *q* = true. But, if both *p* and *q* are true (both paths lead to the restaurant and are chosen), or both are false, then *p* ⊕ *q* = false.
