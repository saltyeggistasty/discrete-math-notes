# **Conditional Statement**

## Main Idea
Let *p* and *q* be propositions, the conditional of *p* and *q* is *p* → *q* implies if *p* then *q*. *p* is called hypothesis while *q* is called conclusion or consequences.

| *p*     | *q*     | *p* → *q* |
|-------|-------|--------|
| true  | true  | true   |
| true  | false | false  |
| false | true  | true   |
| false | false| true   |


My example:
  - Let *p*: Chickens can fly to mars and *q*: 2 + 1 = 3, the conditional of *p* and *q* is *p* → *q*, which reads "If chickens can fly to mars, then 2 + 1 = 3".<br>*p* → *q* is only false when *p* is true and *q* is false. In all other cases, it is true.
