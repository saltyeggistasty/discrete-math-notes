# **Conditional Statement**

## Main Idea
Let *p* and *q* be propositions, the conditional of *p* and *q* is *p* → *q* implies if *p* then *q*. *p* is called hypothesis while *q* is called conclusion or consequences. Important to note that in Discrete Mathematics, conditional statements is independent of cause and effect between hypothesis and the consequences, in other words it is independent of causality. *p* → *q* Doesn't mean *p* causes *q*, it just says everytime *p* is true then *q* must also be true.

| *p*     | *q*     | *p* → *q* |
|-------|-------|--------|
| true  | true  | true   |
| true  | false | false  |
| false | true  | true   |
| false | false| true   |


My example:
  - Let *p*: Chickens can fly to mars and *q*: 2 + 1 = 3, the conditional of *p* and *q* is *p* → *q*, which reads "If chickens can fly to mars, then 2 + 1 = 3". *p* → *q* is only false when *p* is true and *q* is false. In all other cases, it is true.
  - Let *p*: "Linux is an open source operating system" and *q*: "Anyone can view and modify Linux's source code.", the conditional of *p* and *q* is *p* → *q*: "If Linux is an open source operating system, then anyone can view and modify Linux's source code."
